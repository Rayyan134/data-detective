Safety guardrails

🔒 Sandbox

The model can only name a registered tool and its declared parameters. Code, shell and file access are rejected before anything runs.

🎯 Grounding

A plan may only reference columns that exist; a genuine miss is refused, a clear typo is repaired and shown.

🕶️ PII redaction

Chosen fields are described by name and type, but no value from them reaches any prompt or the evidence.

✅ Honesty

Any number in the narrative that no tool computed is flagged as unverified, never presented as evidence.
