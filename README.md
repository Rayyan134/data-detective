# Data Detective

**An Autonomous AI Data Investigation Agent**

Data Detective is an AI-powered application designed to help users investigate datasets and discover meaningful insights through natural-language questions.

Users will be able to upload CSV datasets, ask questions, and receive structured investigations supported by Python-based analysis, visualisations, and evidence-backed findings.

## Project Goals

- Make exploratory data analysis more accessible.
- Explore practical applications of agentic AI.
- Build an AI agent capable of planning and executing multi-step analytical tasks.
- Prioritise reliability, transparency, and explainability.

## Planned Features

- **Data Profiling:** Inspect dataset structure, data types, missing values, and distributions.
- **Autonomous Investigation:** Interpret user questions, plan analytical steps, and select appropriate tools.
- **Visualisations:** Generate relevant charts using actual dataset results.
- **Insight Generation:** Produce understandable, evidence-backed findings.

## Technology Stack

| Technology | Purpose |
|---|---|
| Python | Core application |
| Pandas | Data manipulation |
| NumPy | Numerical analysis |
| LLM API | Natural-language understanding and planning |
| LangGraph | Agent workflow orchestration (if needed) |
| Matplotlib | Data visualisation |
| Streamlit | User interface |

## Development Approach

The initial version will focus on CSV datasets, a single agent, predefined analytical tools, and validated results.

The goal is to demonstrate genuine agentic behaviour rather than simply wrapping an LLM in a chatbot interface.
